Dynamic Tab Hibernation, ergonomic pill tabs, and a floating glass Omnibox. AETHER 0.0.3 introduces dormant tab suspension logic that automatically unloads heavy WebKit WebContent processes after 15 minutes of inactivity or under memory pressure, caching high-fidelity viewport snapshot covers and navigation state tokens for instant, seamless reconstitution with zero data loss. The user interface has been completely modernized with ergonomic rounded pill tabs featuring 8px corner radii, capsule geometry, and radiant oceanic active indicator bars with ambient glow. The Omnibox now floats with native acrylic blur (.ultraThinMaterial), oceanic focus ring, and an integrated security indicator pill displaying TLS lock status, insecure HTTP warnings, and local file badges.
